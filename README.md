# JobHub Full Stack

A portfolio-ready job marketplace built with Spring Boot, React, PostgreSQL, Spring Security and JWT.

## Features
- Candidate and employer roles
- JWT authentication and role-based authorization
- Employer job posting and management
- Candidate job search, filtering and applications
- Application status tracking
- Profile management
- PostgreSQL persistence with Flyway
- REST API validation and global exception handling
- Unit/integration test foundation
- Docker Compose for local development

## Stack
Java 21 · Spring Boot · Spring Security · JPA/Hibernate · PostgreSQL · React · Vite
